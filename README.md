#Secure Office Network

#About the Project

This project involves designing a secure office network using Cisco Packet Tracer.

#Project Objectives

- Create a network for different office departments.
- Configure VLANs for network segmentation.
- Implement IP addressing and subnetting.
- Configure inter-VLAN routing.
- Control network traffic using Access Control Lists (ACLs).
- Test connectivity between network devices.

#Tools Used

- Cisco Packet Tracer
- GitHub

#Project Status

In Progress

#Learning Goals

This project helps me develop practical skills in computer networking, network security, and network troubleshooting.
